# Python-practice-
# Day 2: Python Functions & Data Structures

This folder contains my Day 2 Python practice. The goal is to improve my
understanding of reusable functions and Python's built-in data
structures.

## Topics Covered

-   Functions and return values
-   Local and global scope
-   Lists, tuples, dictionaries, and sets
-   List comprehensions
-   `*args` and `**kwargs`
-   Lambda functions
-   `filter()` and `map()`

## Practice Questions

### Basic Level

1.  Create a function that takes two numbers and returns their sum.
2.  Create a function that checks whether a number is even or odd.
3.  Create a function that returns the sum of a list of numbers.
4.  Create a function that finds the largest number in a list.
5.  Create a function that removes duplicate values from a list.
6.  Create a tuple of five numbers and find its maximum, minimum, and
    length.
7.  Create a student dictionary containing name, age, and marks, then
    display each value.

### Intermediate Level

1.  Sort a list of numbers in ascending order using a function.
2.  Count the frequency of each word in a sentence using a dictionary.
3.  Find common elements between two lists using sets.
4.  Use list comprehension to create a list containing only even
    numbers.
5.  Store student names and marks in a dictionary, then find the highest
    marks and average.
6.  Use `*args` to calculate the average of multiple numbers.
7.  Use `**kwargs` to accept and display student information.
8.  Use a lambda function to calculate the square of a number.

### Advanced Level

1.  Clean a list of names by removing duplicates and empty values, then
    sort it.
2.  Create an employee management program with add, update, delete, and
    display functions.
3.  Generate a result summary for multiple students, including total,
    average, highest, and lowest marks.
4.  Count word frequencies in a paragraph and identify the most frequent
    word.
5.  Sort a list of student dictionaries by marks in descending order.
6.  Create a function that uses both `*args` and `**kwargs`.
7.  Use `filter()`, `map()`, and lambda functions to select even numbers
    and calculate their squares.
8.  Demonstrate local and global variables using functions.

## Daily Task: Three Reusable Functions

The main task is to implement and test these functions:

### 1. `remove_duplicates(data)`

Removes duplicate values from a list.

### 2. `sort_data(data)`

Returns the supplied data in sorted order.

### 3. `generate_summary(data)`

Generates a numerical summary containing:

-   Total
-   Average
-   Maximum
-   Minimum
